# scaffold a Next.js project on Workers
Link: https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/
```bash
pnpm create cloudflare@latest my-next-app --framework=next
```

# shadcn/ui for Next.js Existing Project
Link: https://ui.shadcn.com/docs/installation/next
Run the shadcn init command to set up shadcn/ui in your project.
```bash
pnpm dlx shadcn@latest init
```
Add Components
```bash
pnpm dlx shadcn@latest add button
```
